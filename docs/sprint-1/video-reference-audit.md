# Video Reference Audit

Source: “Mobile View & Native apps.mp4”, 3:34, supplied through Google Drive.
Reviewed representative frames at 0:19, 0:29, 0:49, 1:19, 1:49, 2:19,
2:49 and 3:19.

## Recorded visual hierarchy

1. Bright royal-blue brand/search header.
2. Dark gray time rail: Live, Today, 1H, 3H and Tomorrow.
3. Short edge-to-edge promotional carousel.
4. Compact category shortcuts with blue outline icons.
5. Dense dark event cards with minimal radius and gray odds footer.
6. Horizontally scrolling league chips immediately above bottom navigation.
7. Fixed black five-tab bar: Live, Sport, Tickets, Casino and Menu.
8. Selection opens a compact bottom bet slip with stake presets and a green
   full-width submit action.
9. Casino uses the same blue header and bottom bar, plus Lobby/Providers/
   Jackpots/Themes controls, search/filter row and two-column game tiles.
10. Ticket submission uses a dimmed page with centered progress feedback.
11. Game launch transitions to an embedded/full-screen provider loading state.

## Match requirements

- Match placement, relative heights, spacing density and dark/blue/gray color
  relationships closely enough for a side-by-side demo.
- Retain horizontal rails rather than converting them to large vertical cards.
- Retain small rectangular odds cells rather than rounded pills.
- Retain the bottom navigation order and compact label/icon treatment.
- Keep the voice agent out of the main content stack; expose it through the
  header microphone, Voice screen and native system surfaces.
- Replace PSK/Amusnet and provider artwork with original FEG/demo-safe identity,
  generic promotional art and deterministic game placeholders.
- Remove captured browser/emulator chrome; reproduce only the app content.
