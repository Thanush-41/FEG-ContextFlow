# Sprint 13 — Promotions, content and support

Sprint 13 turns the discovery and support entries in Menu into complete native
flows. It provides a small, deliberate demo catalogue rather than placeholder
links: three promotions, first-party news and guides, help articles and
responsible-play guidance.

## Scope

- Three typed demo promotions, including the casino three-game tour.
- Authenticated, owner-specific and idempotent promotion opt-in.
- Filtered news, guide, help and responsible-play content APIs.
- Native discovery lists and readable article-detail screens.
- Explicit demo-only, no-cash-value and voice-confirmation boundaries.
- Typed contracts, API-client methods and Android/iOS parity.

Community remains a separate social-data sprint so its follow, reaction and
shared-ticket rules can be completed and verified as one unit.
