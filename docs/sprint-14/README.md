# Sprint 14 — Community and shared demo tickets

Sprint 14 completes the Community entry as a native, public demo feed. Users
can react with owner-specific state and copy a shared ticket into the same
authoritative slip used by the sportsbook, live flow and ticket placement.

## Scope

- Three deterministic public demo posts covering live betting, casino and
  clearer voice requests.
- Authenticated reaction toggle with per-owner state.
- Shared two-pick demo ticket with version-checked server-side copying.
- Selection resolution through `SlipsService`, preserving current odds,
  suspension and compatibility rules.
- Native Community feed and expanded-slip handoff on iOS and Android.
