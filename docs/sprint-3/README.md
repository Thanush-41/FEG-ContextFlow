# Sprint 3 — Mobile Sports Shell

Sprint 3 turns the approved recording-matched design into a working bare React
Native screen. It intentionally uses deterministic demo content so navigation
and domain APIs can be added without changing the visual baseline.

## Delivered

- compact FEG blue header and native-app strip;
- time-period rail and promotional voice-agent module;
- quick product links and dense dark offer cards;
- interactive three-way odds and sticky bet-slip affordance;
- five-item bottom navigation matching the reference hierarchy;
- expandable voice panel wired to the existing native word-count, speech,
  notification, widget and Live Activity bridge.

The next sprint extracts navigation and implements offer, live, event, bet-slip
and ticket routes against the shared contracts.
